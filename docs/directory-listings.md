# Directory listings — Leisure Oaks Park

Why this matters: Google decides which "Leisure Oaks" you are, and how
well-known the park is, partly from how consistently the same name, address and
phone appear across the web. Today a search for the park's own name ranks around
position 11 (page 2) — that is the gap these listings close. RV directories also
rank on their own for "RV parks Peoria," so a listing is a second way to be found.

**The single most important rule: paste the fields below exactly, character for
character, on every site.** "Ave" vs "Avenue", or a different phone format, can
read as a different business. If a site insists on its own format (e.g. spells
out "Avenue"), accept it — don't fight it — but never change the name or phone.

## What not to do

- Don't buy a bulk "submit to 500 directories" service. Those create junk
  listings with mangled data, which is the exact problem this is meant to fix.
- Don't use a tracking phone number or a different one per site.
- Don't list the park under a second name ("Leisure Oaks RV Park", "Leisure Oaks
  Campground"). One name only, the one above.
